# 🚀 TestHub — Современная веб-платформа для онлайн-тестирования

Полноценная автономная система онлайн-тестирования для образовательных учреждений, преподавателей, репетиторов и корпоративных тренингов.

---

## 🎯 Основные возможности

### Для преподавателя (Администратора):
- 🔐 **Безопасная авторизация** по JWT с хешированием паролей (`bcrypt`).
- 🛠️ **Интуитивный конструктор тестов**:
  - Настройка названия, описания, проходного процента.
  - Настраиваемый таймер (в минутах) или режим без ограничения.
  - Перемешивание вопросов и вариантов ответов.
  - Включение/отключение мгновенного показа правильных ответов ученикам.
- ❓ **Поддержка различных типов вопросов**:
  - Одиночный выбор (Radio).
  - Множественный выбор (Checkbox).
  - Текстовый ввод (точный или регистронезависимый ответ).
  - Настраиваемая стоимость вопросов в баллах и пояснения к ошибкам.
- 🔗 **Публикация и раздача тестов**:
  - Мгновенная генерация уникального кода и прямой ссылки.
  - Встроенный QR-код для моментального сканирования камерой смартфона.
  - Быстрое переключение статуса (активен / приостановлен).
- 📊 **Глубокая аналитика и журнал участников**:
  - Список всех сдач с фильтрацией по ФИО и учебным группам/классам.
  - Детальный просмотр попытки каждого ученика (какие варианты он выбрал, где ошибся, баллы за каждый вопрос).
  - Анализ сложности вопросов (Item Analysis) — шкала процента верных ответов по каждому вопросу.
  - **Экспорт в Excel / CSV** (с корректной поддержкой кириллицы UTF-8 BOM).

### Для ученика:
- 📱 **Доступ без регистрации**: переход по ссылке или ввод кода на главной странице, ввод имени и группы.
- ⏱️ **Удобный таймер**: обратный отсчет времени с предупреждением при последней минуте и автоматической сдачей теста по истечении времени.
- 🛡️ **Античит (Защита ответов)**: сервер **никогда не передает** правильные ответы (`is_correct`) клиенту до завершения теста. Все вычисления производятся строго на защищенном бэкенде.
- 🏆 **Интерактивный экран результатов**: анимация конфетти при успешной сдаче, итоговый балл, процент и подробный разбор вопросов с пояснениями.

## 🛠️ Стек технологий

- **Backend**: Node.js, Express, встроенная база данных SQLite (`node:sqlite`), `bcryptjs`, `jsonwebtoken`, `cors`.
- **Frontend**: React 19, Vite, Tailwind CSS, Lucide Icons, `qrcode.react`, `canvas-confetti`.
- **База данных**: SQLite (файл `server/data/database.sqlite`), не требует установки внешних СУБД.

## 🚀 Быстрый запуск

### 1. Установка зависимостей и сборка
```bash
npm run setup
```
*(установит пакеты для сервера и клиента и выполнит сборку)*

### 2. Запуск готового сервиса
```bash
npm start
```
Платформа будет доступна в браузере по адресу: **http://localhost:5000**

### 3. Режим разработки (HMR)
Для активной разработки фронтенда с горячей перезагрузкой:
- В первой консоли: `npm run server` (сервер на порту 5000)
- Во второй консоли: `npm run client` (Vite dev-сервер на порту 5173 с автоматическим прокси к API)
